# Architecture Decision Records (ADR)

This directory documents all significant architectural and structural decisions made in Themis.

## Format
Every decision must follow the standard MADR / Nygard format:
- **Title:** `ADR-XXXX-<short-title>.md`
- **Status:** Proposed | Accepted | Superseded | Deprecated
- **Context:** The problem or requirement prompting the decision.
- **Decision:** The chosen path and architecture.
- **Consequences:** Positive, negative, and neutral trade-offs.
